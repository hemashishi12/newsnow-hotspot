GPT-SoVITS API

06

爆款文章提示词

点击话题的“AI 写头条文章”时，系统会把这段提示词与该话题的新闻、帖子和热评一起发给当前 AI 模型。

修改只影响之后生成的文章；每次保存的版本都会追加存档，历史结果也会保留当时的提示词。
07

AI 联网权限

控制文章生成时是否允许 AI 使用联网搜索工具访问热榜链接。关闭后仅使用已采集的新闻、帖子和热评资料。

08

深度长文提示词

点击话题的“AI 写深度长文”时，系统会把这套独立提示词与同样的新闻、帖子和热评资料一起发给当前 AI 模型。

这套提示词只影响深度长文；每次保存的版本都会追加存档，与普通头条文章互不覆盖。
09

总榜排序权重

调整三项归一化指标在综合排序中的影响。可填写任意非负数，保存时会自动按合计值归一化，首页排序立即更新。

归一化预览 共振 50% · 升温 30% · 高热 20%
10

模块指标与总榜公式

页面只展示一张总榜，以下三类指标用于打标和合并排序。α={{ scoring.get('rank_exponent', 1.2) }}，历史窗口为最近 {{ recent_runs }} 次。

A / CURRENT

多平台共振

Hₜ(T) = Σₚ wₚ · ((Nₚ − rₚ,ₜ + 1) / Nₚ)α

对话题 T 当前所在的每个平台求和。wₚ 是平台权重，Nₚ 是该平台榜单长度，rₚ,ₜ 是当前站内名次；同平台只取名次最高的一条。

排序字段
Hₜ(T) 降序
入选条件
至少 {{ scoring.get('min_platforms', 2) }} 个平台
B / RISING

快速升温

R(T) = |Pₜ| · max(0, slope(H)) · n · (1 + Grank)

slope(H) 是近 n 次综合热度的线性回归斜率；|Pₜ| 是当前平台数；Grank 是相邻采集中各平台名次分正向改善的加权平均。

排序字段
R(T) 降序
最低分
{{ scoring.get('rising_min_score', 0.02) }}
C / SUSTAINED

持续高热

S(T) = Σᵢ₌ₜ₋ₙ₊₁t Hᵢ(T)

累加近 n 次采集的综合热度。话题必须仍在最新一轮出现，并达到最低出现覆盖率，避免昙花一现的话题进入该模块。

排序字段
S(T) 降序
最低覆盖率
{{ '%.0f%%'|format(scoring.get('sustained_min_presence_ratio', 0.5) * 100) }}

总榜分 = {{ '%.2f'|format(section_weights.current) }} × H/max(H) + {{ '%.2f'|format(section_weights.rising) }} × R/max(R) + {{ '%.2f'|format(section_weights.sustained) }} × S/max(S)。未入选某标签时，该项记 0 分。AI 只负责事件聚类，不能修改排序数据。
